# ManoEdit

Site estático em HTML, CSS e JavaScript, com três páginas: Início, Produtos e Sobre. Não requer instalação nem processo de build.

## Visualizar no computador

Abra `index.html` no navegador ou publique a pasta `Clientes/ManosEdit` com GitHub Pages.

## Publicar com GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie o conteúdo desta pasta para a raiz do repositório (o arquivo `index.html` deve ficar na raiz).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e salve.
5. Aguarde a publicação. O GitHub mostrará o endereço do site nessa página.

Para associar um domínio próprio, configure-o em **Settings → Pages → Custom domain** e aplique no provedor de DNS os registros exibidos pelo GitHub.
